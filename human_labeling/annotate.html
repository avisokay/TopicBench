How to label
  • Every cluster for a paper is on screen at once. Read them all before writing anything — a label is a choice about how one cluster differs from its neighbours.
  • Revise freely. Going back to change an earlier label as the set becomes clearer is the intended way to work.
  • Short noun phrases, in the register you would use in a paper.
  • Tick unsure rather than guessing silently, and use the paper note for anything the label cannot carry.
  • Your work saves in this browser as you type. Export the file at the end and send it back.
